# IEP-P1-008 RFQ品目管理

実装日: 2026-09-08

## 実装

- RFQ詳細画面で品目一覧、検索、追加、編集、論理削除、復元。
- 原文、翻訳説明（手入力）、商品紐付け、メーカー、品番、商品名、数量、単位、希望納期、状態、備考。
- 商品を選ぶとメーカー・品番・商品名・単位を転記。転記後の情報は案件品目の値として保持。
- 保存先: rfqs/{rfqId}/items/{rfqItemId}。自動IDは編集・削除・復元でも維持。
- 明細No.は rfqs/{rfqId}/itemCounters/sequence を使い、品目作成と同一トランザクションで採番。削除番号は再利用しない。
- archivedAtによる論理削除。createdAt/updatedAt/archivedAtはサーバー時刻。
- Rulesは認証、親案件の存在、入力値、番号・作成日時の不変性を検証。物理削除は禁止。

## ブラウザ確認手順

1. npm run dev で起動し、ログインして /rfqs から既存案件の詳細を開く。
2. 「品目を追加」で原文、数量、単位、希望納期を入力して保存。
3. 別の品目を商品マスターから選択して追加。メーカー・品番・商品名・単位の転記を確認。
4. 再読込して2品目と異なる明細No.が表示されることを確認。
5. 編集で数量、翻訳説明、納期、備考を変更。再度編集を開き、希望納期がずれないことを確認。
6. 原文が空、数量が0または負数、単位が空のとき保存が拒否されることを確認。
7. 品目検索で原文・翻訳・品番による絞込を確認。
8. 「削除」でキャンセル時は残り、確定時は非表示になることを確認。「削除済みを表示」から復元し、元の明細No.で戻ることを確認。
9. 別のRFQに品目が混ざらないことを確認。
10. 2つのブラウザで同じRFQへ同時に品目を追加し、明細No.が重複しないことを確認。
