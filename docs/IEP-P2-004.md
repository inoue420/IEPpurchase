# IEP-P2-004 仕入先見積明細管理・金額計算

実装日: 2026-09-09。ユーザー動作確認待ち。Firestore Rulesはieppurchase本番へ反映済み。

## 実装

- RFQ詳細の仕入先見積一覧に「明細」を追加。明細一覧・追加・編集、品名・品番・数量・単位・単価・送料・納期・税区分・税率・備考を保存。
- 保存先は `supplierQuotes/{quoteId}/items/{itemId}`。`rfqItemId` は同一RFQの有効品目に限定。`productId` はそのRFQ品目から引継ぎ、関連する見積依頼がある場合は依頼対象品目であることも検証。
- 数量は0より大きく1,000,000以下、小数3桁まで。既存RFQ品目の数量は変更せず、範囲外の数量は保存時に拒否。単価は0〜1,000,000,000円、明細・見積総額は1,000,000,000,000円以下。
- 商品代・送料それぞれに税抜／税込／非課税と0〜100%（0.01%単位）の税率を保持。非課税の税率は0。商品代の円未満と各構成額の税端数を切捨て。数量を整数の千分率、計算をBigIntで扱う。
- 送料は明細に手動配分。ヘッダーのshippingTotalは税込送料の集計表示で、総額へ再加算しない。未入力は未確認、0円は送料無料として明示入力。
- 初めて明細を登録するときは、手入力ヘッダーの総額との差を表示し、確認チェック後に計算額へ切替。入力済みの見積全額へ明細を足し込まない。
- 明細・ヘッダー合計・両方のrevision履歴を同じトランザクションで保存。ヘッダー履歴は更新前Snapshotも保存。版番号によって同時編集の上書きを拒否。
- 明細登録後はヘッダーの仕入先・依頼参照・合計を直接変更不可。見積番号・日付等の編集は引き続き可能。物理削除は不可。
- 1回の保存は1明細。Rulesは変更明細ID、旧新の金額差とヘッダーの差を検証し、履歴なし・親更新なし・不正合計・集計外の追加明細を拒否。全明細をRulesから走査せず、任意件数へ順次追加できる。
- 見積書と端数差がある場合は差額を表示。調整額・税率別一括計算は追加していない。

## 動作確認

1. `/rfqs` から品目のある案件を開き、仕入先見積を登録するか既存見積を選ぶ。
2. 「明細」→「明細を追加」。案件品目を選択し、単価1,000円、数量2、送料500円、商品と送料とも税抜10%に設定する。
3. 明細小計2,500円・税250円・総額2,750円を確認。初回切替の確認にチェックして保存。
4. 別品目も追加し、ヘッダーが各明細総額の合計になることを確認。送料を400円＋200円と配分した場合に二重加算されないことを確認。
5. 明細の数量・価格を編集し、保存後の合計と再読込後の値を確認。税込／非課税、納期未指定／指定も確認。
6. 負額、数量0、小数4桁、送料未入力の保存が拒否されることを確認。
7. 同じ見積を2つのタブで編集し、片方の保存後に古い方を保存すると競合メッセージが出ることを確認。
8. 明細登録後の「詳細・編集」で、仕入先・依頼・金額が編集不可で、見積番号・備考は変更できることを確認。
