# IEP-P2-006 品目別購入候補一覧・比較画面

実装日: 2026-09-09。ユーザー動作確認待ち。

## 実装

- RFQ詳細へ「品目別購入候補の比較」を追加した。
- 有効なRFQ品目を選択し、その品目に紐づく仕入先見積明細とEC購入候補だけを一覧表示する。
- 候補種別、仕入先・販売者、品名・品番、数量・単位、単価、送料、送料込総額、納期、在庫、取得日、URL、備考を比較できる。
- 送料込総額、単価、納期の昇順で並べ替えできる。不明値は末尾に表示する。
- 送料・総額・納期・在庫の未確認、仕入先見積の期限切れ、RFQ必要数量・単位との条件差を明示する。
- 取消・アーカイブ済みのRFQ品目、撤回・アーカイブ済みの仕入先見積は比較対象外とする。
- 比較結果は表示専用。購入先採用・数量分割はIEP-P2-007で実装する。

## ユーザー動作確認

1. `/rfqs` から複数品目を持つ案件を開く。
2. 仕入先見積明細とEC購入候補を同じ品目に2件以上登録する。
3. 画面下部の「品目別購入候補の比較」で、両方の候補が同じ表に表示されることを確認する。
4. 総額・単価・納期の並べ替えが正しいことを確認する。
5. 品目を切り替え、別品目の候補が混在しないことを確認する。
6. 送料・納期・在庫が未確認の候補、および期限切れの仕入先見積に注意表示が出ることを確認する。
7. 必要数量または単位と異なる候補に「数量・単位条件が異なります」と表示されることを確認する。
8. 候補のない品目で空状態の案内が表示されることを確認する。
