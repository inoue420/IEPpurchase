# IEP-P2-013 楽天検索連携

状態: 実装・自動確認済み、ユーザー動作確認待ち（2026-09-10）。

## 実装
- 認証必須Callable `searchRakutenItems` をasia-northeast1へデプロイ済み。
- 楽天市場検索API 20260701を利用。検索語のみ送信し、最大20件を表示。
- RAKUTEN_APPLICATION_ID / RAKUTEN_ACCESS_KEYはSecretとしてサーバー参照。値は記録しない。
- 非秘密設定 RAKUTEN_SITE_URL=https://sharprise.jp/ をfunctions/.env.ieppurchaseに設定。楽天登録済みドメインとしてReferer / Originに使用。
- RFQ詳細のEC購入候補から「楽天で検索」→商品選択→既存登録画面へ値を引継ぎ。
- 送料は未確認、数量は1を初期値とし、案件品目の単位を表示。送料・税率・購入可能数量・単位・規格の確認チェック後にSnapshot追加保存。
- 検索結果の商品名は案件品目選択時にも保持。取得日時のローカル表示を修正。
- 未認証、検索語不正、接続失敗、検索制限、楽天の拒否応答を処理。上流のエラー本文や認証値を利用者へ返さない。
