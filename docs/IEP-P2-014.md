# IEP-P2-014 — Amazon Business API 利用準備

作成日: 2026-09-11  
状態: ユーザー確認待ち（Amazon側の利用申請・承認待ち）

## 結論

IEPpurchase の「Amazon商品候補取得」には、Amazon Business API の **Product Search API** が用途に適合する。日本（JP）は Far East 対象で、日本向けエンドポイントは `https://jp.business-api.amazon.com` である。

Amazon.co.jp 商品ページのスクレイピングや、用途の異なる Selling Partner API は使用しない。Amazon Business API はAmazon側の事前承認が必要で、ロールも審査後にAmazon側が割り当てる。承認前に API キーや秘密値を取得・設定する実装は行わない。

## 採用候補の方式

| 項目 | 判断 |
| --- | --- |
| 利用方式 | Amazon Business API / Product Search API |
| 想定ロール | `Business Product Catalog` |
| 用途 | RFQ品目の商品・オファー検索。確認後に既存の `marketplaceOffers` Snapshot として保存 |
| 対象地域 | 日本（JP、Far East） |
| 今回の対象外 | 注文、カート、購入実行、注文履歴、配送・支払情報の取得 |
| 承認前の代替 | 既存の「EC購入候補を登録」による手入力を継続 |

今回必要なのは比較用の候補取得だけなので、Ordering API などの追加権限は申請しない。

## ユーザーにお願いする準備

1. [Amazon Business API Onboarding](https://docs.business.amazon.com/lang-ja_JP/docs/onboarding-overview) のアクセス申請を行う。用途には「社内の資材調達システムで、Amazon Business JP の商品・オファーを検索し、RFQごとの比較候補として表示する。発注は実行しない」と記載する。
2. 承認・登録案内を受けたら、Amazon Businessアカウント、Solution Provider Portal（SPP）アカウント、開発者プロファイル、アプリクライアントを案内に従って作成する。
3. Product Search API 相当（`Business Product Catalog`）の用途を伝える。ロールは任意選択ではなくAmazon側の審査・割当である。
4. アプリクライアント情報、LWAリフレッシュトークン等の秘密値は、チャット、管理シート、Git、`.env` に貼り付けない。取得できた事実と日付だけを共有する。

## 承認後の実装方針

- 秘密値は Firebase Functions の Secret 管理にのみ設定し、ブラウザへ返さない。
- Cloud Function で LWA アクセストークンを発行・更新し、JP エンドポイントへ Product Search API を呼び出す。
- 検索結果は、送料・数量・税・規格をユーザー確認してから、既存の楽天連携と同様に `marketplaceOffers` へ不変 Snapshot として保存する。
- 検索結果から購入・発注は実行しない。まずサンドボックスで認証・レスポンス変換・エラー表示を確認してから、本番検索を有効化する。

## 公式根拠（2026-09-11確認）

- [Onboarding overview](https://docs.business.amazon.com/lang-ja_JP/docs/onboarding-overview): 利用にはAmazon Businessチームの承認が必要で、承認後にアカウント・SPP・開発者プロファイルを登録する。ロールはAmazon側が割り当てる。
- [Amazon Business API roles](https://docs.business.amazon.com/lang-ja_JP/docs/amazon-business-roles): `Business Product Catalog` はProduct Search APIでカタログ・関連オファーを検索でき、FEを対象とする。
- [Amazon Business API endpoints](https://docs.business.amazon.com/lang-ja_JP/docs/ab-api-endpoints): 日本のエンドポイントは `https://jp.business-api.amazon.com`。
- [Product Search API static sandbox guide](https://docs.business.amazon.com/lang-ja_JP/docs/product-search-api-static-sandbox-guide): Product Search APIには本番前に確認できる静的サンドボックスがある。
