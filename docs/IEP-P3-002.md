# IEP-P3-002 freee OAuthコールバック・Secret設定

## 実装内容

- `beginFreeeOAuth` が認証済み利用者ごとに10分で失効するstateを発行し、freeeの事業所選択付き認可画面へ遷移します。
- `freeeOAuthCallback` はstateを一度だけ照合してから認可コードを交換します。
- Client ID、Client Secret、取得したアクセストークン・リフレッシュトークンはFirebase Secret Managerだけで扱います。Firestore、ブラウザ、ログには保存しません。

## デプロイ前の設定

1. `FREEE_CLIENT_ID`、`FREEE_CLIENT_SECRET`、`FREEE_OAUTH_TOKENS` の3つのSecretを作成します。最後は初期値として任意のダミー値を設定します。
2. Cloud Functions実行サービスアカウントに、`FREEE_OAUTH_TOKENS` のSecret Version Adderを付与します。
3. Functionsをデプロイし、freeeアプリのコールバックURLへ `https://asia-northeast1-ieppurchase.cloudfunctions.net/freeeOAuthCallback` を設定します。

OAuthトークンの保存には実行サービスアカウントの追加権限が必要で、認可・Secret設定・デプロイは本番外部サービスへ影響するためユーザー作業として実施します。
