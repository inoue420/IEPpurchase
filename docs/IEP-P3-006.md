# IEP-P3-006 RFQ品目の一括手入力

ステータス: 完了（2026-09-18・ユーザー確認OK）

## 実装内容

- RFQ詳細の品目欄に「表からまとめて追加」を追加。
- タブ、パイプ（`|`）、カンマ区切りの見出し付き表に対応。
- 見出しからメーカー名、品番、商品名／詳細、数量、単位、備考を判定。
- 最大50品目をプレビューし、行ごとの修正、登録対象の選択、入力エラー表示に対応。
- 最終確認後、選択した全品目を同一Firestoreトランザクションで連番登録。途中登録は行わない。

## 対象外

- CSV・Excelファイル取込（IEP-P3-007）
- メールボックスとの自動連携
- OCR・AI抽出

## ユーザー動作確認

1. RFQ詳細を開き、品目欄の「表からまとめて追加」を押す。
2. 次の表を貼り付けて「プレビュー」を押す。

   ```text
   メーカー名	品番	詳細	数量	単位	備考
   ABC	A-001	六角ボルト	10	本	至急
   XYZ	B-002	交換部品	2	個	
   ```

3. 2行目の数量や備考を修正し、登録しない行があればチェックを外す。
4. 「登録内容を確認」を押し、件数を確認して「登録する」を押す。
5. 選択した品目だけが連番で一覧へ追加され、修正内容が保持されていることを確認する。
6. 数量を0にした行はエラーとなり、登録対象に選べないことを確認する。
