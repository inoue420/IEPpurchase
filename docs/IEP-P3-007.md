# IEP-P3-007 RFQ品目のCSV・Excel取込


## 実装内容

- RFQ詳細の「表からまとめて追加」で、CSV、Excel（`.xlsx`、`.xls`）ファイルを選択できます。
- 先頭シートを既存の一括入力と同じ見出し判定、行別プレビュー、修正、選択、バリデーション、最終確認、連番一括登録へつなげます。
- ファイルは10MB以下、登録対象は50品目以下です。ブラウザ内で読み取るだけで、外部サービスへアップロード・送信しません。

## ユーザー動作確認

1. RFQ詳細の品目欄で「表からまとめて追加」を押します。
2. 「CSV・Excelファイルを選択」から、1行目を `メーカー名、品番、詳細、数量、単位、備考` としたファイルを選びます。
3. シート名と行別プレビューを確認し、必要なら修正します。
4. 登録する行を選び、「登録内容を確認」→「登録する」を押します。
5. 選んだ行だけが連番で登録されること、51件以上または形式外ファイルは登録前にエラーになることを確認します。

CSV・Excel取込を実装中です。
