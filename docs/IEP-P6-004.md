# IEP-P6-004 Google Cloud Vision OCR品目候補化

## 画面の動作

RFQ詳細の品目画面から、JPEG、PNG、GIF、WebP、BMP、ICO、またはPDF（10MB以下、先頭5ページ）を選ぶ。スクリーンショットは貼り付け枠をクリックしてCtrl+Vでも選択できる。OCR結果は自動確定せず、抽出テキスト、平均文字信頼度、品目候補を表示する。利用者は品目説明・メーカー名・品番・数量・単位を修正し、選択した行だけを最大50件までRFQ品目として一括登録する。候補表の「列をまとめて編集」では、選択行または全候補行を対象に、列のコピー・移動・消去ができる。たとえば「移動」「品目説明」「品番」を選ぶと、品目説明を品番へ移し、元の品目説明を空欄にする。

ファイルはOCR処理のためGoogle Cloud Visionへ送信される。RFQ品目の登録時にファイル本体を保存しない。

## 最終調整の操作

1. 自動抽出後、まず登録したい候補行にチェックを付ける。すべてを対象にする場合は、列編集の対象で「すべての候補行」を選ぶ。
2. 「列をまとめて編集」で、操作（コピー／移動／消去）、元の列、必要な場合は先の列を選択する。
3. 「まとめて適用」を押す。移動と消去では必須項目が空欄になる場合があり、その行は自動で登録対象から外れる。
4. 表の各セルと状態を確認し、必要な行だけをチェックして登録する。候補を保存するまでFirestoreのデータは変更されない。

## 表の整列

罫線付き画像では、まず画像上の縦線・横線を検出し、十分な格子が確認できた場合は縦罫線を列境界として優先する。罫線が検出できない画像、PDF、罫線が途中で欠けた表では、Visionが返す単語の座標を使って同じ高さの文字を行にまとめ、見出し（メーカー、製品名・詳細、品番、数量、単位）の横位置と、複数データ行で繰り返される大きな横方向の空白から列境界を復元する。中央寄せされた見出しだけには依存しない。行番号など最初の見出しより左側にある列は登録候補から除外する。単位列がない表は「個」を初期値とし、製品名に英数字の型番が含まれる場合は品番候補へ反映する。

読み取り精度を上げるには、表だけが入るように切り取り、傾きを抑え、見出しを含め、文字が潰れない解像度で貼り付ける。複数の表は1枚ずつ処理する。

## 本番有効化前のユーザー作業

1. Google CloudプロジェクトでCloud Vision APIを有効化する。
2. 利用予算、アラート、上限、および画像データの送信・保存条件を確認して設定する。
3. Vision APIだけに制限したAPIキーを作成し、ブラウザ公開用ではなくCloud Functions用として扱う。
4. `GOOGLE_CLOUD_VISION_API_KEY` をFirebase Secret Managerへ設定する。
5. `extractVisionOcrText` とHostingを本番反映する。画像を用いた接続確認は、利用者が明示的に実行する。

認証情報の値は、ソースコード、Git、Firestore、管理シート、チャットには保存しない。
