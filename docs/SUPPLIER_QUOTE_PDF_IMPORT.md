# 仕入先見積PDF取込の要件

更新日: 2026-11-06

## 要件変更

ユーザー指示により、仕入先見積PDF取込の抽出・照合要件を以下へ変更する。

### 品番が重複した場合

- PDF内に同じ品番が複数ある場合は、上側に記載された行の仕切単価を確認画面に表示する。
- 複数ページの場合は前のページを優先し、同一ページ内では上側の行を優先する。
- 品番の比較には既存の正規化（全角・半角、空白、ハイフン表記の統一）を使用する。
- 下側の行は同じ品番の追加候補として表示しない。仕切単価が異なる場合も上側の行を優先する。
- 同じ品番が複数あることだけを理由に、RFQ品目との照合対象から除外しない。
- RFQ側に同じ品番の品目が複数ある場合は、各RFQ品目に対して上側のPDF行の仕切単価を表示する。

### 数量の後に備考がある場合

- 数量の後に備考が記載されていても、品番と仕切単価を抽出する。
- 「本体のみ」「2個同時急速充電」や型番を含む備考があっても、対象行を除外しない。
- 備考に含まれる数字や型番を、仕切単価・数量として扱わない。
- 備考がない行も引き続き抽出する。

## 反映操作

- 抽出した仕切単価は、既存どおりRFQ品番と照合して確認画面に表示する。
- 利用者が対象品目を選択し、反映操作を行った時点で回答単価と状態「見積取得済み」（`quoted`）を同一トランザクションで保存する。
- すでに発注済み・入荷済みの品目は、その状態を維持して回答単価だけを更新する。
- 保存前に全対象を読み直し、削除済み・キャンセル・存在しない品目が含まれる場合は全件の保存を止める。未選択品目は更新しない。
- 反映成功時は品目一覧の検索条件を解除し、取り込んだ品目を表示する。キャンセル・失敗時は検索条件を保持する。
- 品目検索欄とPDFパスワード欄は、ブラウザによるログイン情報の自動入力を抑制する。

## 受入条件

1. 提示された6行の見積で、MP181DZ・BL1860B・DC18RD・A-75306・UB186DZを抽出・照合できる。
2. BL1860BがPDF内に2行あっても、RFQのNo.2とNo.6の両方を確認対象に表示できる。
3. 確認画面の仕切単価は、MP181DZが12,510円、BL1860Bが両方15,400円、DC18RDが17,800円、A-75306が2,300円、UB186DZが8,730円となる。
4. 同一品番の上側と下側で仕切単価が異なる場合も、上側の単価だけを表示する。
5. 数量の後に文字・数字・型番を含む備考があっても、品番・仕切単価を正しく抽出する。
6. 検索欄に一致しない文字列がある状態で取り込んでも、成功後に検索が空になり、反映した品目を表示する。
7. 反映した未処理等の品目は「見積取得済み」となり、再読込後も回答単価・状態が保持される。
8. 保存失敗時は単価・状態を一部だけ更新せず、ダイアログのエラーを表示する。検索条件も保持する。
